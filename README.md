# Melo Art Gallery

Site vitrine artistique pour présenter les oeuvres, le processus de création, les informations légales et la prise de contact.

## Technologies

- React 18
- TypeScript 5
- Vite 6
- Tailwind CSS 3
- React Router DOM
- Framer Motion
- React Hook Form + Zod
- Radix UI (Dialog)
- React Icons

## Prérequis

- Node.js 18+ (recommandé: Node.js 20 LTS)
- npm (ou pnpm / yarn)

## Installation

1. Installer les dépendances:
	 npm install

## Commandes disponibles

- Lancer en développement:
	npm run dev

- Générer le build de production:
	npm run build

- Prévisualiser le build en local:
	npm run preview

## À propos du lint

Le script lint n'est pas encore configuré dans ce projet.
Si vous souhaitez l'ajouter, vous pouvez intégrer ESLint puis créer un script npm run lint.

## Build production

Le build compile TypeScript puis bundle l'application via Vite.
Les fichiers de sortie sont générés dans le dossier dist.
