# Melo Art Gallery

Site vitrine artistique pour présenter les oeuvres, le processus de création, les informations légales et la prise de contact.

## Technologies

- React 18
- TypeScript 5
- Vite 6
- Tailwind CSS 3
- React Router DOM
- Framer Motion
- React Hook Form + Zod
- Radix UI (Dialog)
- React Icons

## Prérequis

- Node.js 18+ (recommandé: Node.js 20 LTS)
- npm (ou pnpm / yarn)

## Installation

Installer les dépendances:

```bash
npm install
```

## Commandes disponibles

- Lancer en développement:

```bash
npm run dev
```

- Générer le build de production:

```bash
npm run build
```

- Prévisualiser le build en local:

```bash
npm run preview
```

- Lancer le lint:

```bash
npm run lint
```

## À propos du lint

Le script lint n'est pas encore configuré dans ce projet.
La commande ci-dessus est fournie pour la suite, mais elle ne fonctionnera qu'après l'ajout d'ESLint et d'un script lint dans package.json.

## Build production

Le build compile TypeScript puis bundle l'application via Vite.
Les fichiers de sortie sont générés dans le dossier dist.
